How it works
Cryptographic proof
via biometric verification.
01
SDK generates a keypair on first use
The iOS SDK uses Secure Enclave; Android uses the hardware-backed Keystore. The private key is generated on-chip and never leaves the device. The public key is registered with Vouchflow.
02
Your backend issues a challenge
A single-use, time-limited challenge string is generated by your server and passed to the SDK. Each verification requires a fresh challenge — replay attacks are structurally impossible.
03
The device signs the challenge
The SDK asks the user to authenticate with Face ID, Touch ID, or biometric. On success, the Secure Enclave signs the challenge with the private key. The signature is sent to Vouchflow.
04
Vouchflow validates and returns confidence
Vouchflow verifies the signature against the registered public key, checks attestation level, and returns a confidence signal. Your backend receives the result and proceeds accordingly.
// Step 1: First launch // SDK auto-enrolls on first verify() POST /v1/enroll { "public_key": "MFkwEwYHKoZI...", "attestation": "o2NmbXRvYXBw...", "platform": "ios" } // Response { "device_id": "dvc_01HZXK9M...", "attestation_level": "hardware" }
// Step 2: Your backend const challenge = crypto. randomBytes(32). toString('hex') // Pass to SDK as ch_... // Expires in 5 minutes // Single-use enforced by Vouchflow
// Step 3: On-device // Secure Enclave signs challenge // Biometric required to unlock key POST /v1/verify { "device_id": "dvc_01HZXK9M...", "challenge": "ch_9f2a8e1b...", "signature": "MEUCIQDx7mN3..." }
// Step 4: Vouchflow response { "verified": true, "confidence": "high", "platform": "ios", "biometric": "face_id", "device_age_days": 142 } // Signature valid ✓ // Hardware attestation ✓ // Proceed with signup
Device reputation network

Gets smarter
with every verification.

Devices that opt into the Vouchflow Network contribute to a cross-app reputation graph. A device verified across 50 apps over 18 months with no anomalies is trusted. A device that appeared two weeks ago verifying across 30 apps is suspicious.

Built right
Inherit iOS and Android
device security.
Private key never leaves the chip
Keypairs are generated inside the Secure Enclave (iOS) or hardware-backed Keystore (Android). Vouchflow never sees, stores, or touches your private key.
Zero PII in the network graph
No names, emails, or phone numbers are ever attached to device tokens. The reputation graph is built on behavioural continuity — not identity data.
Single-use, hardware-signed challenges
Every verification is a fresh cryptographic challenge signed by the device's private key. Challenges expire in 5 minutes and cannot be replayed — structurally ruling out the attacks that make SMS verification weak.
