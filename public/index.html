The authorization gap

Empower AI agents to sign up, pay, and act
on behalf of real humans.

OAuth tokens were designed for browsers in 2012. Passwords were designed for humans typing, not agents holding. SMS was never designed for anything that matters. The new generation of software needs an authorization primitive built for the moment when a machine acts and a human must consent — provably, specifically, irrevocably.

What's broken

Token-based authorization

Every existing auth primitive bridges agents to human intent through long-lived bearer tokens. Tokens have no opinion about what they're authorizing.

  • OAuth scopes are coarse; a "write" token authorizes any write, not a specific one
  • Tokens leak. Once exfiltrated, they authorize anything within their lifetime
  • No cryptographic binding to specific actions — only to a class of actions
  • No proof a human approved this transaction right now
  • SMS, biometric prompts, magic links — all device-blind or replay-vulnerable
Vouchflow's primitive

Bound, biometric, hardware-rooted

Each authorization is a single signature over this specific action, produced by hardware the user is holding right now, with their finger on it.

  • The signature is over the action payload, not a token. Modify the payload, break the signature
  • The signing key lives in Secure Enclave, Keystore, or platform authenticator. Never exfiltrable
  • Biometric gating means a real human consented at signing time
  • Single-use challenges. Structurally replay-proof
  • Cross-app reputation network adds device history as a continuous signal
The Vouchflow API

Two primitives.
Every platform.

The same trust model from iOS to Android to Web. Verify when you need to know a real human is present. Sign when you need to know they approved this exact thing.

verify ()

Prove a real human is present.

The original Vouchflow primitive. Replaces SMS OTP, magic links, and CAPTCHA with a hardware-backed biometric ceremony in under two seconds. The user's device proves itself; the network reputation graph tells you whether that device has earned trust.

Returns a confidence signal — high, medium, or low — so your backend can decide what to do next.

iOSAndroidWeb
TypeScript verify() 
const result = await Vouchflow.shared.verify({
  context: 'sensitive_action',
});

// result.verified           → true
// result.confidence         → 'high'
// result.deviceToken        → 'dvt_01HZX...'
// result.signals            → { deviceAgeDays: 142 }
signPayload ()

Bind intent to a specific agentic transaction.

The primitive built for what's coming next. signPayload produces a cryptographic signature over the exact action being authorized — a mandate, a transaction, a key release, a permission grant — that's verifiable months or years later as proof of consent.

    currency: 'USD',

  minConfidence: 'high',
