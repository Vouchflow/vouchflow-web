Getting started
Complete these steps to run your first verification.
0 of 3 steps complete
1
Install the SDK
Swift Package Manager · CocoaPods · Gradle

Add Vouchflow to your iOS or Android project. Choose your platform below.

Xcode — File → Add Package Dependencies 
https://github.com/Vouchflow/ios-sdk
Or add to Package.swift 
dependencies: [
  .package(
    url: "https://github.com/Vouchflow/ios-sdk",
    from: "1.0.0"
  )
]
// Add VouchflowSDK to your app target
Requires iOS 15+, Xcode 15+, Swift 5.9+. Add the App Attest entitlement to your app target before calling any SDK method — Target → Signing & Capabilities → + Capability → App Attest.
settings.gradle.kts — add repo 
repositories {
    maven {
        url = uri("https://maven.pkg.github.com/vouchflow/android-sdk")
        credentials {
            username = providers.gradleProperty("gpr.user").get()
            password = providers.gradleProperty("gpr.key").get()
        }
    }
}
build.gradle.kts — add dependency 
dependencies {
    implementation("dev.vouchflow:android-sdk:1.0.0")
}
Add your GitHub username and a Personal Access Token (read:packages scope) to ~/.gradle/gradle.properties as gpr.user and gpr.key.
2
Initialise with your API key
VouchflowConfig · apiKey + customerId · UIKit & SwiftUI

Initialise Vouchflow once at app launch with VouchflowConfig. You'll need your API key and customer ID from the dashboard. The sandbox key is pre-filled — safe to commit during development.

Swift · UIKit AppDelegate 
import VouchflowSDK

func application(_ application: UIApplication,
  didFinishLaunchingWithOptions ...) -> Bool {
    try? Vouchflow.configure(VouchflowConfig(
        apiKey: "vsk_sandbox_4xK9mN2pL8qR7tW3yH6jD1",
        customerId: "cust_..."
    ))
    return true
}
Swift · SwiftUI App 
import VouchflowSDK

@main
struct MyApp: App {
  init() {
    try? Vouchflow.configure(VouchflowConfig(
      apiKey: "vsk_sandbox_4xK9mN2pL8qR7tW3yH6jD1",
      customerId: "cust_...",
      environment: .sandbox
    ))
  }
}
3
Run your first verification
async/await · context enum · physical device required

Call Vouchflow.shared.verify(context:) using Swift async/await. Pass a context (.signup, .login, or .sensitiveAction) — it's stored on the verification record and included in webhook payloads. Run on a physical device.

Swift 
do {
  let result = try await Vouchflow.shared.verify(
    context: .signup  // .login · .sensitiveAction
  )
  // result.verified       — Bool
  // result.confidence     — .high / .medium / .low
  // result.deviceToken    — pass to your server
  proceedWithSignup()

} catch VouchflowError.biometricCancelled(let sessionId) {
  // User tapped Cancel — show retry
  showRetry()

} catch VouchflowError.biometricFailed(let sessionId) {
  // Offer email fallback
  showEmailFallback(sessionId: sessionId)

} catch VouchflowError.minimumConfidenceUnmet {
  // Device posture issue — do not offer fallback
  handleLowConfidence()

} catch {
  handleError(error)
}
