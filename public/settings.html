Webhook endpoints
Vouchflow sends signed POST requests to your endpoints on verification events.

The first endpoint is Vouchflow-hosted — useful for testing without a receiver.
Events
Choose which events are sent to each endpoint.
verification.completed
Fired on every verification attempt — verified, degraded, or failed.
verification.degraded
Fired when confidence is low and a fallback was triggered.
device.enrolled
Fired when a new device keypair is registered for the first time.
device.anomaly_detected
Fired when an anomaly flag is raised on a device — reinstall, attestation downgrade, rapid spread.
