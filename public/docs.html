Get started

Quickstart

From install to your first verified device in under 5 minutes. Works with iOS Secure Enclave, Android Keystore, and WebAuthn. No SMS, no fallback logic to write—enrollment happens automatically.

  1. Install the SDK
    Add Vouchflow to your iOS, Android, or Web project.
  2. Initialize with your API key
    Your sandbox write key is pre-filled below—safe to commit during development.
  3. Run your first verification
    Call verify()—enrollment happens automatically on first use. The SDK manages all state.

Install the SDK

Choose your platform. The sandbox key in all examples below is your actual key — no substitution needed.

Swift Package Manager 
// Package.swift
dependencies: [
    .package(
        url: "https://github.com/Vouchflow/ios-sdk",
        from: "2.0.0"
    )
]
⚠ App Attest required for high confidence (iOS) Add the App Attest entitlement to your app target. Without it, automatic enrollment on first verify() will succeed but confidence is capped at .medium. See App Attest setup →
Gradle (build.gradle.kts) 
dependencies {
    implementation("dev.vouchflow:android-sdk:2.0.0")
}
⚠ Minimum requirements Android 9.0+ (API 28). No Google Play Services dependency — Keystore Attestation works on every Android device with TEE/StrongBox (KeyMaster 3+).
npm 
npm install @vouchflow/web
TypeScript 
import { Vouchflow } from '@vouchflow/web'

Vouchflow.configure({
  apiKey:      'vsk_sandbox_••••••••••••••••',
  environment: 'sandbox',
  rpId:        'app.example.com',
  rpName:      'Example',
})
⚠ Web SDK — Private Beta Sandbox-only access during private beta. See the full Web SDK docs → for verification, payload signing, React hooks, and the email-OTP fallback flow.

Initialise

Call Vouchflow.configure(VouchflowConfig(...)) once at app launch. Only your write-scoped apiKey is required — there is no customerId.

Swift 
import VouchflowSDK

// SwiftUI
@main struct MyApp: App {
  init() {
    try? Vouchflow.configure(VouchflowConfig(
      apiKey: "vsk_sandbox_••••••••••••••••",
      environment: .sandbox
    ))
  }
}

Run a verification

Enrollment is handled automatically on first call. You do not need to call enroll() separately.

Swift 
do {
  let result = try await Vouchflow.shared.verify(
    context: .signup  // .login · .sensitiveAction
  )
  // result.verified    — Bool
  // result.confidence  — .high / .medium / .low
  // result.deviceToken — pass to your server
  proceedWithSignup()

} catch VouchflowError.biometricCancelled(let sessionId) {
  showRetry()

} catch VouchflowError.biometricFailed(let sessionId) {
  let fallback = try await Vouchflow.shared.requestFallback(
    sessionId: sessionId,
    email: currentUserEmail,
    reason: .biometricFailed
  )
  showOTPInput(expiresAt: fallback.expiresAt)

} catch VouchflowError.minimumConfidenceUnmet {
  handleLowConfidence()

} catch {
  handleError(error)
}
Run on a physical device App Attest requires a physical device (iOS 15+). The simulator returns confidence: .medium — expected, not a bug. Requires Xcode 15+ and Swift 5.9+.
