1. The Services

1.1 What Vouchflow Does

Vouchflow provides a device-native identity verification API that enables developers to verify that a real, previously-registered device is present, using cryptographic proof generated by the device's Secure Enclave (iOS) or hardware-backed Keystore (Android). The Services include:

  • APIs and SDKs for iOS and Android
  • A developer dashboard for monitoring verifications and managing API keys
  • A cross-app device reputation network (the "Network")
  • Documentation, support tools, and related services
